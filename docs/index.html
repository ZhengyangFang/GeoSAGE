The current PyHydroGeophysX release package predates the complete plugin interface. The steps below install the current source checkouts into one small, reusable uv environment.

02

Install once.

Keep the two repositories beside each other. Inputs and generated results stay outside Git.

⌘ GitDownload source code ↗ uv uvFast environment manager ↗
PowerShell
mkdir GeoSAGE-Workspace
cd GeoSAGE-Workspace
git clone https://github.com/geohang/PyHydroGeophysX.git
git clone https://github.com/ZhengyangFang/GeoSAGE.git

uv venv .venv-studio --python 3.12
uv pip install --python .venv-studio\Scripts\python.exe `
  -c GeoSAGE\constraints-tested.txt `
  -e ".\PyHydroGeophysX[desktop,desktop-3d]" `
  -e ".\GeoSAGE"
Terminal
mkdir GeoSAGE-Workspace && cd GeoSAGE-Workspace
git clone https://github.com/geohang/PyHydroGeophysX.git
git clone https://github.com/ZhengyangFang/GeoSAGE.git

uv venv .venv-studio --python 3.12
uv pip install --python .venv-studio/bin/python \
  -c GeoSAGE/constraints-tested.txt \
  -e "./PyHydroGeophysX[desktop,desktop-3d]" \
  -e "./GeoSAGE"

The environment is created once and reused. GeoSAGE does not publish input data, calculated models or reports in its code repository.

03

Open Professional Studio.

Launch the shared PyHydroGeophysX interface with the GeoSAGE plugin installed.

Windows
.\.venv-studio\Scripts\geosage-studio.exe --module one_click
macOS / Linux
./.venv-studio/bin/geosage-studio --module one_click
1
The Studio opens with its normal PyHydroGeophysX experience.

AQUAH remains the default assistant. Open the Assistant panel and choose GeoSAGE when you want the geological modeling workflow.

04

Run your first workflow.

Use the same interface for a new inversion or for an existing GeoSAGE result.

  1. 1
    Select GeoSAGE

    Open Assistant, then choose GeoSAGE from the assistant menu.

  2. 2
    Choose a task

    Open Data & reports. Select View results, New inversion or AI interpretation.

  3. 3
    Add your input

    Choose a survey folder for a new run, or an existing GeoSAGE inversion folder for inspection and interpretation.

  4. 4
    Check before running

    Use Check inputs & preview configuration. GeoSAGE reports missing physical parameters instead of guessing them.

  5. 5
    Run at your pace

    Use step-by-step approval to inspect every action, or Auto to report for one continuous workflow.

  6. 6
    Review the evidence

    Open Results for data fit and model sections, Visualization for the 3D model, and Report for the reviewed interpretation.

What stays local

Your research files remain yours.

Numerical input, inversion models, figures and reports are stored in your selected local workspace. The public GeoSAGE repository contains code, templates and tests only.
